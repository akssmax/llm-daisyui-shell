# Layout recipes

Use these as **semantic** composition patterns; map to regions before assigning pixel positions.

## Centered hero stat

- **Focus**: one large number or metric center mass vertically ~35–45% from top.
- **Secondary**: short headline above or below stat; caption in smaller type.
- **Spacing**: large vertical gap between stat and caption (48–96px equivalent).

## Split layout

- **Left 45–50%**: headline + bullets or narrative.
- **Right 50–55%**: visual, chart placeholder, or secondary card.
- **Divider**: optional vertical rhythm gap ≥ 64px between columns on 1080px-wide artboards.

## KPI row

- **Three to four** equal columns across width; each: label + number.
- Use consistent card height and baseline alignment for numbers.

## Social carousel slide

- **1080×1350** safe zone: keep critical text in upper **60%**; branding/CTA in lower **40%**.
- Single clear message per slide; avoid multi-paragraph walls.

## Presentation title slide

- **1920×1080**: title left or centered in upper third; subtitle mid; footer strip for logo/date.

## Dashboard grid

- **Dense** but grid-aligned cards; 12-column mental model; 24–32px gutters.

## Timeline (lightweight)

- Vertical spine with **3–5** steps; alternating left/right callouts only if space allows; otherwise single side.
